First time on this device

  1. Open GitHub's new key page.
  2. Set Resource owner to 228thBlackSkulls.
  3. Repository access: Only select repositories, then pick 228thBlackSkulls.github.io.
  4. Permissions: set Contents to Read and write.
  5. Tap Generate token, copy it, and paste it below.

The key stays on this device. Don't share it with anyone: whoever has it can change the site.
