# 228th Black Skulls Corps Website

The public website for the 228th Black Skulls Corps.

- **Site:** https://228thblackskulls.github.io/
- **Edit page:** https://228thblackskulls.github.io/admin/

## How editing works

All the text and links on the site (Discord invite, leadership, schedule, FAQ and so on) live in `content.json`.
The edit page shows the form on one side and a live preview of the site on the other. Changes show in the preview as you type; press Publish and GitHub Pages republishes the site about a minute later.
Signing in uses a GitHub fine-grained key with Contents read/write on this repo. It is stored only in that browser.

`index.html` holds the design, animations and logo. Leave it alone unless you are changing the look of the site.
Uploaded images (like leadership portraits) go in `images/`.
