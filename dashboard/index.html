Past events

The standing weekly schedule on the main site's Operations section. Add, edit or remove what happens each day. Pick which division's calendar each one goes on (Both shows on each). Pick All day for things like a day off, or No set time yet to show TBD. Everyone sees the times in their own time zone.

New briefing

Roles are listed from highest to lowest. Drag the ⠿ handle to reorder. Members can hold several roles, and each briefing chooses which roles can see it. Tick what each role is allowed to do on this Dashboard, like Discord. Admin can always do everything, and only Admin can change roles.
