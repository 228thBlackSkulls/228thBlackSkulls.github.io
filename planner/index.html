Set up the planner

  1. In the 228thBlackSkulls org on GitHub, create a public repo named 228th-ops (tick "Add a README").
  2. Make a fine-grained key: Settings → Developer settings → Fine-grained tokens. Resource owner 228thBlackSkulls, Only select repositories: 228th-ops, Permissions → Contents: Read and write. Pick the longest expiry offered.
  3. Paste it below. Only give it access to 228th-ops: everyone with the planner link can use it.
